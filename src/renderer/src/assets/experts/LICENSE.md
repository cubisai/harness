# Expert avatars

Each `<expert-id>.svg` (and `<team-id>--<member-id>.svg` for a team member) was generated with DiceBear 9 from the expert's id as the seed.

- Design: Notionists by Zoish (https://heyzoish.gumroad.com/l/notionists), licensed CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).
- Generator: DiceBear (https://www.dicebear.com), MIT. The bundled files were generated once; imported experts use the same generator as a dependency.

An expert without a file here (an imported one, say) gets a portrait generated the same way at runtime (`@dicebear/core` + `@dicebear/notionists`, MIT; the Notionists art is CC0 1.0).
