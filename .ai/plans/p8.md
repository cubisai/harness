## P8.2 Grader/judge calibration
Repeat-grade stability (flaky command graders found by re-running the reference N times); a model-judge grader kind only with labeled calibration examples and a blinded, order-randomized pairwise mode; calibration report.
## P8.3 Bounded optimizer loop
One surface per experiment (prompt / skill description / retrieval profile / model-effort), versioned candidates, train failures inspected, validation selects, holdout only for release; stop on noise-level gains, regressions, stalls or budget; every experiment recorded.
## P8.4 Lesson replay, promotion, retirement
Replay a captured case with and without the candidate lesson (learn_replays), transfer check on other cases, promote only with both, helpful/harmful counters, retire/undo, revalidate on model/runtime change.
