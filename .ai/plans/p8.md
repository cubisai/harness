## P8.2 design (ready to brief; two parallel workers)
- **Worker A — judge grader: evals/lib/judge.ts, evals/lib/graders.ts, evals/lib/types.ts, test/eval-judge.test.ts.** New Grader `{ type: "judge"; rubric: string; calibration: string /* evals/judges/<name>.json */; required?; weight? }`. judge.ts: `judgeOnce(ask, rubric, transcript)` → { pass, why } (strict JSON reply); `pairwise(ask, rubric, a, b, rng)` (blinded: labels "Response 1/2", order randomized, the swap undone in the result); `calibrate(ask, rubric, examples: { transcript, label: boolean }[])` → { accuracy, agreement, n }. A judge counts only when its calibration file reports accuracy ≥ 0.85 on ≥ 10 labelled examples; otherwise the grader returns pass false with why "judge uncalibrated" and the trial is "ungraded", not failed. `ask` is injected (GradeInput gains `ask?`); no model call in tests.
- **Worker B — stability: evals/lib/calibrate.ts, evals/run.ts, test/eval-calibrate.test.ts.** `--stability N`: run validateTask N times per task (zero model calls) and report tasks whose no-op/reference verdicts flip (flaky command graders, timing). Exit 1 on any flip. Also `--calibrate-judge <name>` once judge.ts exists (runs calibrate with the configured background model; prints accuracy).
