# AGENTS.md

Instructions for coding agents (opencode workers and others) working in this repository.

- **UI work**: any change under `src/renderer/**` follows `DESIGN.md` (flat "Ink Flat" system: tokens, type, spacing, components, motion, pre-ship checklist). Read it before editing styles or components. Use tokens from `src/renderer/src/styles/app.css`, never literal colors.
- **Project rules**: see `CLAUDE.md`. As a worker, never run `opencode` or delegate; stay inside the repository; don't run git.
