# Copy Checklist Reference

Run every piece against all five checks. Fix failures in the copy rather than noting them; the checklist exists to be run.

## Checks

| Check | Ask | Fails when |
|-------|-----|------------|
| Clarity | Would the target reader get the message on one pass? | A second reading is needed, or a word the audience never uses survived |
| Specificity | Could the name be swapped onto another product unnoticed? | "Fast results" or "easy to use" stands where a stated fact should be |
| Proof | Does every claim trace to a positioning proof point? | A superlative, number or testimonial appears that the proof list does not carry |
| Tone | Does it sound like one competent person saying one true thing? | Hype stacks up, or two pieces read as different voices |
| Accessibility | Can it be read as plain text, by eye or ear? | Sentences run past about 25 words, links hide their destination, or the action is unclear |

## Sentence rules

- One idea per sentence; split anything that carries two.
- Active voice: someone does something, not something is done.
- Replace "significantly", "dramatically" and friends with the number or the concrete case; if you have neither, drop the claim.

## Pass rule

A piece is ready when all five checks pass and every claim still names the proof point it leans on.
