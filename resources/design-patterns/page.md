# Page patterns (scrolling site: landing, pricing, portfolio, docs home)

## Composition
- **Hero = H1 + one outcome sentence + one primary action + one real artefact.** The H1 names the product or its promise in ≤ 8 words, ≤ 2 lines at 1280px. The artefact is the product itself (an editor with real text, a dashboard with real numbers, a photo the brief implies), never an abstract blob or icon grid.
- **Asymmetric by default**: text on columns 1–6, artefact on 7–12, or a full-bleed artefact under a left-set headline. Centre at most one moment per page (often the closing call to action).
- Let the artefact overlap an edge (a metadata chip hanging off its corner, a card breaking the section line): it reads designed.
- **Every section changes shape.** One equal 3-up row per page at most; others are a 2-column split, a numbered list, one large screenshot, a quote, a table. Vary section padding with weight: 64 / 96 / 128px, related groups tighter.
- Nav: logo left, 3–5 links, one action. Footer: the real destinations in 1–2 rows, links underlined.

## Type and spacing
- Display 56–96px, tracking −0.02 to −0.03em, line-height 1.0–1.1. Headings 28–40px at 1.15–1.25. Body 16–18px at 1.5–1.65, measure 55–72ch, left-aligned.
- Heading to its paragraph 8–16px; section to section ≥ 64px. One spacing scale.

## Anatomies
- **Pricing**: plans side by side; the recommended one gets a 2px primary border and the only filled button (no "Popular" badge). Each plan: name, one-line who-it's-for, price in tabular figures with unit ("/ user / month"), button, then "Everything in Free, plus:" and 4–6 concrete features. Below: a comparison table with grouped section rows and "—" for absent, then a 2-column FAQ (title + contact link left, questions right with hairline dividers).
- **Proof**: one named customer with role, company and a specific outcome ("cut review time from 3 days to 4 hours"), not a row of five-star cards.
- **Portfolio**: the work leads. Large images cropped with intent, project title + year + role in small type, an index list of projects rather than identical tiles.
- **Docs home / content**: left nav with grouped sections and the current page marked, a 65ch column, a right-hand "On this page", code blocks with a copy button and language label.

## Content
Write domain-true copy: product name, real feature nouns, believable numbers with units and dates, people with full names and roles. Calls to action name the outcome ("Join the waitlist", "Start 14-day trial"), never "Learn more" or "Get started" alone.

## Refuse → do instead
- Eyebrow label over every heading → put the noun in the heading; number sections editorially only if the brief is editorial.
- Gradient text, blurred blobs, glass panels, glow shadows → solid colour, a real artefact, surface tone for depth.
- Hero metric row (10k+, 99.9%) → one sourced number, or none.
- Three identical icon cards → a list, a split, or three different module shapes.
- Centred everything, identical section padding → left-set grid, varied rhythm.
