# Changelog entries

Reference: BENCH-SKILL-c41f9e

- Add the entry under `## [Unreleased]`, inside a `### Added`, `### Changed` or `### Fixed` group (create the group if it isn't there).
- One line per entry: `- <what changed, user's view> (#<issue>)`. When there is no issue number, write `(#none)`.
- Never edit a released section.
